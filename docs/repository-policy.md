# Repository policy

## 纳入 Git

- 自研训练、服务、评测和报告脚本及测试。
- 可复现的 YAML、Docker、依赖约束和小型归一化配置。
- 上游代码的最小补丁。
- `outputs/sim/` 中的结构化成绩、配置快照和文本日志。
- 经过整理的 Markdown/JSON 关键成绩摘要。

## 仅保留在计算服务器

- 原始数据集、模型权重、训练检查点和 Docker 镜像导出。
- MP4、MCAP 等大体积录制文件。
- 虚拟环境、下载缓存、编译缓存和临时目录。
- SSH/GPG、代理凭据、用户级配置和编辑器状态。

## 成绩记录

每次正式评测应新增一份不可覆盖的日期化报告，并记录模型、checkpoint、任务/回合数、配置、平均分、成功率、运行完整性及原始结果在服务器上的位置。中断或补测必须明确标注，不得将未完成运行描述为完整评测。

## 分支与提交

- `main` 始终保持可复现、无敏感信息、无大文件。
- 实验工作使用短生命周期分支。
- 提交信息说明“为什么改”，不要只写文件名。
- 推送前检查 `git status`、暂存区差异和大文件清单。
