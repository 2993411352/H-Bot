WSS 回归使用实际 TLS、序列化、`sessions-v1` 路由和原有会话测试，但 CPU 测试的模型是 mock；测试报告标记 `MOCK_POLICY_LOCAL_WSS_PASSED`，不能当作真实权重 GPU 推理验证。验收时发现本地 TLS 握手间歇性超时；本地测试端关闭不需要的 TLS 会话票据后，完整 8 项测试连续 6 轮通过。该改动仅作用于一次连接的回环测试服务端，证书验证仍开启，正式客户端 TLS 设置不变，也没有添加自动重试。尚未将这一现象归因于已确认的上游缺陷。

本次没有抢占 GPU 再做真实权重推理，也没有申请或连接新的正式评测链接。换机后必须先执行 `test.sh --check`，再在空闲 GPU 执行 `test.sh --self-test`。测试成功证明接口及运行环境可用，不证明模型的仿真成功率。

JAX 全新环境安装在本次主机的 Git 代理返回 407 时中止，因此没有把“同版本既有环境测试通过”写成“JAX 全新安装实测通过”。安装脚本固定上游 commit 与锁文件；新机器需具备可用的 GitHub 下载通道。
