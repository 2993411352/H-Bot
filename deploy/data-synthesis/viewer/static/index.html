回放与标注操作

  1. 从左侧选择任务与轨迹。W 编号对应采集者，同名 Episode 属于不同来源时会分别保存。
  2. 先完整播放，观察三路相机。暂停后等待“精确帧已就绪”，用左右方向键逐帧查看。
  3. 按实际动作划分接近、抓取、搬运、对齐、释放、稳定等区间。I设置起点、O设置终点。
  4. 四方块堆叠通常搬运三次；标第1/2/3次循环。方向操作可能只推动，不要硬套抓取。
  5. 遮挡或无法确认时标“待复核 / 无法判断”，不要猜接触与成功。必要等待不能当作无效静止。
  6. 补齐所有帧，填写标注者并确认审核完成。可先保存草稿，之后继续编辑；标为“不用于正向模仿”的区间会保存在导出标签中。

快捷键：空格 播放/暂停 · ← / → 逐帧 · Shift+← / → 跳10帧 · I / O 标边界 · Ctrl+S 保存草稿。

区间包含起止帧；相邻区间不能重叠。导出标签用于后续筛选，网页不会删除原始文件，也不会自动改动训练配置。
